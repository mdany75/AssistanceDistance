# AssistanceDistance

Site statique (HTML/CSS/JS sans dépendance) pour obtenir le numéro AnyDesk d'un usager.
- `index.html` : page unique ; `config.js` : titre, code d'accès, webhook Teams.
- Pas de build. Tester en ouvrant `index.html` ou `python3 -m http.server`.
- Textes en français. Cible : usagers Windows.
